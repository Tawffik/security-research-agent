# Knowledge quality bar (BOLA-stage standard)

Every trusted CASE should prefer this shape (see CASE-0001 / CASE-0006):

1. Type, status, domain, generalizable  
2. Source / provenance  
3. Security property (explicit)  
4. Actors + resource + object key/action  
5. Observation pattern when vulnerable  
6. Hypothesis statement  
7. Minimum discriminating experiment  
8. Evidence required  
9. Alternatives / disproof  
10. Root cause  
11. Variants (optional)  
12. Skill promotion = No until benchmark + review  

PATTERNs state abstraction + not-the-same-as + experiment.  
PROCEDUREs state when/preconditions/hypothesis/steps/evidence/disproof/stop.  
NEGATIVEs kill common false leads.

Forbidden in trusted knowledge: payload encyclopedias, bulk scrape dumps, universal claims.
